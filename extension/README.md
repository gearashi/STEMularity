# extension/

This folder will hold the STEMularity browser extension. It will link Claude and ChatGPT to STEMularity: it will recognize when a chat is about a known problem, show that problem's progress map, and help report results back. It will be opt-in and privacy-first.

**No code yet.** See the [browser extension section of the roadmap](../docs/ROADMAP.md#browser-extension) for the plan.
