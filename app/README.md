# app/

This folder will hold "Project: STEMularity", an offline app with the whole STEMularity index. It will have a 90s encyclopedia CD-ROM look and SNES-style pixel art, with STEMgu as your guide. It will sync new data when you are online.

**No code yet.** See the [offline app section of the roadmap](../docs/ROADMAP.md#project-stemularity-offline-app) for the plan.
